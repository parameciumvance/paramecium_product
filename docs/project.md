| Claude Cowork | 2 小時執行預算 | 112 小時執行預算 | 第一週依實際驗收與返工情況校正產能 |

## 交付與商業驗證

- 目標使用者可自行開啟產品，完成核心流程。
- 具備價格、可運作的購買與交付流程、基本說明及問題回報方式。
- 核心流程、必要資料保存與付款交付已驗證，已知阻擋上線的問題已處理。
- 依賴與素材具備可商用的來源紀錄。
- 商業驗證目標：至少五位目標使用者實際試用，爭取第一筆外部客戶付費。這是目標，尚無既有成果。

## 產品候選與待決策事項

1. 工程師通訊測試工具：聚焦一個 Modbus TCP 測試情境、可重跑案例與結果報告。
2. ME-MON 任務陪伴工具：任務、完成紀錄與一個陪伴角色；評估既有原型可重用程度。
3. 原創小型解謎／回合制遊戲：一個核心玩法與少量完整內容。

目前優先比較前兩項。這是待驗證假設，尚未選定產品。真人提供真實痛點與可接觸的使用者類型；Claude 查核替代方案及技術風險；總監彙整後交由老闆決策。

尚待決定：正式產品、首發平台、預算上限、第一批試用對象，以及工程師使用的實際 GitHub 帳戶。
